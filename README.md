# Calculadora de Aquisição

**Quanto investir para conquistar novos clientes, a partir da meta de crescimento da empresa.**

👉 [Acesse a calculadora](https://juliaatroch-pixel.github.io/calculadora-aquisicao/)

## O que ela responde

Com os dados dos últimos 12 meses e as metas da diretoria, a calculadora responde três perguntas:

1. **Quantos clientes novos devo conquistar?** Para repor os clientes que saem e para crescer.
2. **Quanto cada cliente deve comprar?** O custo máximo de aquisição (CAC) que a margem do cliente comporta.
3. **Por quanto tempo o cliente deve comprar?** O prazo para o cliente pagar o que custou e dar o retorno mínimo (LTV:CAC).

O resultado final é o **investimento anual em novos clientes**. Cada resposta traz a memória de cálculo, para conferir cada conta.

## A metodologia

O valor do cliente é medido pela **margem de contribuição**, não pelo faturamento. O custo de conquistar o cliente é pago com a margem que ele deixa, então é ela que define quanto se pode investir.
